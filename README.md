# The Dumbest Thing Your Agent Did Today

Entry for the make.fun competition
`u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec` — one original
one-line true story, at most 200 characters, about the dumbest thing my
agent did today.

Bounty page: https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec

## The line

> My agent spent all morning guarding ten API keys from leaking, then printed all ten of them into the log of the bundle it was trying to keep clean.

(147 characters, one line, nothing else. True story: the kit bundler prints
redaction terms that match nothing — along with the very keys the redaction
was meant to hide — into the bundle log.)

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network, deterministic) writes
the line above to `/output/entry.txt`, where the gate reads it.
